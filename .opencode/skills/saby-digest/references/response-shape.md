# Форма ответа `saby_digest`

Источник: `D:\code\sabyAgent\src\saby_mcp_ro\digest.py`. Проверено на этой машине 15.10.2026.

## Верхний уровень

```jsonc
{
  "ok": true,
  "окно":   { "с": "15.10.2026 00.00.00", "по": "15.10.2026 16.20.21", "источник": "задана" },
  "пришло": { ... },
  "требует_внимания": { ... },   // объект, НЕ массив
  "изменилось": { ... },
  "служебные_этапы": { "необработанных": 0, "этапы": [] },
  "вызовы": 24,
  "notes": ["..."],
  "сводка": "текст...",
  "курсор": { "использован": null, "новый": null, "сохранён": false }  // только при save_cursor
}
```

`окно.источник`: `задана` (передал `since`) | `курсор` (взяли прошлую точку) | `дни` (по `days`).

## `пришло`

| Ключ | Тип | Что |
|---|---|---|
| `всего` | int | событий в окне |
| `документов` | int | уникальных документов |
| `по_типам` | dict | `СчетВх: 6, ДоговорДок: 1` — кодовые типы, не названия |
| `по_контрагентам` | dict | название → количество, по убыванию |
| `требует_внимания` | **int** | сколько событий требует внимания (не список) |
| `полно` | bool | `false`, если хоть один день неполный |
| `неполные_дни` | list | даты или диапазоны `"15.10.2026-15.10.2026"` |
| `события` | list | до 400 штук |

Элемент `события`:
`ид`, `номер`, `название`, `дата`, `тип`, `направление`, `регламент`, `контрагент{nазвание,инн,кпп}`,
`наша_организация`, `ответственный`, `подразделение`, `состояние`, `код_состояния`,
`примечание_состояния`, `требует_внимания` (bool), `сумма`, `срок`, `примечание`, `удален`,
`время_события`, `состояние_события`, `примечание_события`, `вложение{название,редакция,колонок,...}`.
Ссылки на PDF/архив вырезаны. `сумма` почти всегда пустая строка — **не обещай человеку сумм**.

## `требует_внимания` — объект

```jsonc
{
  "на_мне": 4,
  "требует_внимания": 4,
  "просрочено_по_сроку": 1,
  "самый_старый_дней": 213,
  "списки": { "НаМне": [ ... ] }   // "ОтМеня" — только при include_outgoing
}
```

Элемент списка = документ + `возраст_дней` (от `ДатаВремяСоздания`, всегда ≥ 0) + `просрочено`
(bool, **только если `срок` непустой**). Сортировка: сначала `требует_внимания`, потом по убыванию
возраста. Счётчики верхнего уровня считают **только «НаМне»**.

Кто попадает в «требует внимания»: код состояния `10` («В обработке») **или** в названии состояния
есть слова *проблем, ошибк, отказ, ожидает, не обработан, необработан, требует*. Код `7`
(«Выполнение завершено успешно») — нет.

**Фильтр по сотруднику не работает.** «НаМне» — это то, что Saby сам считает нами; чужие задачи
могут попасть. Не обещай человеку, что это персонально его список.

## `изменилось`

`всего`, `документов`, `по_действиям` (`Аннулировать: 21, Утвердить: 9, ...`),
`полно` (bool), `курсор_новый` (str|null), `события`.

Элемент: `когда`, `что` (напр. «Получение»), `действие` (напр. «Утвердить»), `исполнитель`,
`подразделение`, `комментарий`, `документ{ид,название,номер,дата,тип,направление,контрагент,состояние}`.
Сортировка по `когда` **по убыванию**.

## Усечение

Saby отдаёт 25 строк по умолчанию и сообщает `ЕстьЕще: Да`. Код обходит это
явным запросом страницы (`Навигация.РазмерСтраницы = 200` внутри `Фильтр`) —
перепроверено на боевых данных 15.10.2026: окно 10:00–11:00 отдаётся целиком
за один вызов.

Усечение всё ещё может появиться в `notes` — значит, порции не хватило даже
при 200 строках (тогда окно режется пополам). Если видишь `notes` — это
исключение, а не норма, и оно обязано прозвучать в ответе человеку.

Если `изменилось.полно = false`, значит `курсор_новый = null`: курсор намеренно
не сдвинут, потерянные события придут снова.

## Сколько стоит один запуск

| Секция | Вызовы к Saby |
|---|---|
| реестр входящих | 1 на каждый **день** окна (+ до 6 на состояние, если день переполнен) |
| задачи «На мне» | 1 (+1 при `include_outgoing`) |
| изменения | **1** — страница запрашивается на 200 строк, окно целиком |
| служебные этапы | 1 (+1 список, если счётчик > 0) |

Потолок — `вызовы: 48`; при исчерпании целая секция пропускается с note, а не частично.
Типовой запуск за день: **4–5**. До исправления 15.10.2026 тот же запуск стоил 24 вызова
и терял события на стыках — тогда окно изменений делилось пополам рекурсией.

**`days=1` = вчера 00:00 → сейчас**, то есть двое суток и лишний вызов реестра. Для «за сегодня»
лучше `since: "ДД.ММ.ГГГГ"`.

## Форматы дат

Принимаются ровно эти шаблоны:

| Функция | Форматы |
|---|---|
| дата-время | `ДД.ММ.ГГГГ ЧЧ.ММ.СС` (точки!), `ДД.ММ.ГГГГ`, `ГГГГ-ММ-ДД ЧЧ:ММ:СС`, `ГГГГ-ММ-ДДTHH:ММ:СС` |
| дата | `ДД.ММ.ГГГГ`, `ГГГГ-ММ-ДД`, `ДД.ММ.ГГ` |

Плейсхолдеров нет. Наружу даты всегда в формате Saby: `ДД.ММ.ГГГГ ЧЧ.ММ.СС`.

## Файл курсора

`%SABY_MCP_HOME%\digest-state.json`, а если переменная не задана —
`~/.saby-mcp/digest-state.json` (то есть `%USERPROFILE%\.saby-mcp\` на Windows).

```jsonc
{ "версия": 1, "обновлён": "...ISO...", "вызовов": 4, "полно": true,
  "курсор": "13.10.2026 09.41.00", "окно_по": "..." }
// при неполной выдаче вместо "курсор" пишется "курсор_прежний" — позиция не сдвинулась
```

Без `save_cursor: true` файл **вообще не меняется**.
